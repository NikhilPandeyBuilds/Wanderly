1. ABSTRACT

In the modern digital age, travel exploration often involves navigating fragmented, cluttered, and advertisement-heavy web portals that overwhelm travellers with rigid itineraries and unstructured information. Wanderly is a full-fledged, responsive web platform engineered to deliver an intuitive, aesthetic, and interactive travel discovery experience across premier destinations in India—spanning coastal getaways, Himalayan passes, royal heritage circuits, and backwaters.

The platform implements an asynchronous client-server architecture. The presentation tier is built utilizing semantic HTML5, modern CSS3 variables, fluid grid layouts, and modular vanilla JavaScript (ES6+). It features real-time client-side search and category filtering, an interactive trip cost estimator with dynamic pricing formulas, day-by-day interactive itinerary switchers, quick-preview modals, and toast notification queues. The backend service is powered by a zero-dependency Java 21 HTTP Server utilizing com.sun.net.httpserver.HttpServer with Project Loom's Virtual Threads (Executors.newVirtualThreadPerTaskExecutor()), handling static asset hosting and exposing REST API endpoints for destination catalog retrieval, dynamic stats, and booking inquiry persistence.

3. PROBLEM STATEMENT

Existing Challenges: Traditional travel portals present excessive visual clutter, opaque pricing calculators, and heavy third-party framework overheads. Users often encounter friction when attempting to estimate custom trip budgets or explore day-wise itineraries without undergoing cumbersome sign-up processes.

Proposed Solution: Wanderly addresses these challenges by delivering an elegant, distraction-free travel explorer featuring: (i) instant client-side category and keyword filtering; (ii) a live interactive trip cost estimator; (iii) interactive day-by-day tabs; and (iv) a robust, lightweight Java 21 REST backend server.

5. FRONT END AND BACK END TOOLS (SPECIFICATIONS)

5.1 Front-End Tools & Technologies

  • Semantic HTML5: Structured markup using accessible landmarks (<header>, <nav>, <main>, <article>, <footer>).
  • Modern CSS3: Custom Properties (tokens), Flexbox, CSS Grid, glassmorphism (backdrop-filter), smooth hover elevations, and responsive breakpoints.
  • Typography: Google Fonts (*Outfit* for clean UI body text, *Playfair Display* for serif headings).
  • Vanilla JavaScript (ES6+): Asynchronous fetch calls, dynamic DOM manipulation, real-time filtering, modal management, and calculation algorithms.

5.2 Back-End Tools & Technologies

  • Java 21 (OpenJDK / Oracle JDK 21 LTS): Modern object-oriented programming.
  • Embedded Server: com.sun.net.httpserver.HttpServer (zero third-party dependencies required).
  • Concurrency: Project Loom Virtual Threads (Executors.newVirtualThreadPerTaskExecutor()).
  • REST Architecture: Endpoints for /api/destinations, /api/packages, /api/stats, and /api/contact.
