The Story Behind the Project

About Wanderly

Travel is more than reaching a destination — it's about the paths discovered, people encountered, and stories brought home.

Our Vision

Crafted for Curious Explorers

Wanderly was conceived as an intelligent, aesthetic travel exploration platform. It combines curated Indian itineraries with intuitive digital tools to make travel planning as inspiring as the journey itself.

Developed as a comprehensive Java & Web Technologies Mini Project, Wanderly showcases modern software principles: responsive visual design, accessible HTML5, clean modular JavaScript, and a robust Java 21 REST backend server.

Academic & Technical Highlights

Project Architecture

Built to demonstrate clean software design, client-side responsiveness, and lightweight backend services.

🎨 Sleek Frontend

Built with semantic HTML5, modern CSS3 variables, responsive grid systems, micro-interactions, and vanilla JavaScript.

☕ Java 21 Backend

Powered by a zero-dependency Java HttpServer supporting virtual threads, static asset hosting, and REST JSON endpoints.

⚡ Dynamic Utilities

Interactive real-time destination filtering, instant trip budget estimator, modal previews, and booking enquiry capture.
